# ⏱️ Stopwatch App

This is a simple **stopwatch** built using **HTML**, **CSS**, and **JavaScript**. It allows users to **start**, **pause**, **reset**, and track the elapsed time in real-time.

---

## 🚀 Features

- ▶️ Start the stopwatch
- ⏸️ Pause functionality
- 🔄 Reset to zero
- ⏳ Displays time in `HH : MM : SS` format
- ⏱ Built with JavaScript's `setInterval` for precise timing

---

## 🛠️ Technologies Used

- **HTML** – Structure of the stopwatch
- **CSS** – Styling the layout and buttons
- **JavaScript** – Logic to manage time and control functions

---

## 💻 How It Works

1. The user clicks **Start**, and the timer begins counting using `setInterval`.
2. Clicking **Pause** stops the time without resetting.
3. Clicking **Reset** sets everything back to `00:00:00`.
4. Time is updated every second on the display.
